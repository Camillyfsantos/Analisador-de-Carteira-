# Analisador de Carteira

Projeto desenvolvido em Python para cadastrar ativos financeiros e analisar seus resultados.

## Funcionalidades

- Cadastro de ativos financeiros.
- Visualização dos ativos cadastrados.
- Consulta de ativos por código.
- Cálculo do valor investido e do valor atual.
- Cálculo de lucro ou prejuízo e rentabilidade.
- Identificação do ativo com maior lucro.

## Tecnologias

- Python
- Biblioteca `datetime`

## Como executar

1. Instale o Python.
2. Baixe o arquivo `projeto01_carteira.py`.
3. Execute o programa pelo terminal:

```bash
python projeto01_carteira.py
```
